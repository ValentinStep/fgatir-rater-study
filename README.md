# FGATIR Rater Study

A browser-based tool for blinded quality assessment of brain MRI images (FGATIR sequence).

## Access

The study is live at: **https://valentinstep.github.io/fgatir-rater-study/**

Open the link in Chrome, Edge, or Firefox (Safari is not supported). Enter your rater ID when prompted and follow the on-screen instructions.

## What It Does

- Displays anonymized brain MRI volumes in a web-based DICOM viewer
- Presents image series in randomized order to maintain blinding
- Collects structured ratings on image quality (visibility of anatomical structures, diagnostic confidence)
- Supports scrolling, window/level adjustment, and multi-planar reconstruction (axial, sagittal, coronal)
