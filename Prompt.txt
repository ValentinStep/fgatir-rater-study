7. Local-development image strategy
A deployed browser cannot directly read an arbitrary local filesystem path.
Therefore implement a clear local-development ingestion workflow.
Create a script such as:
npm run inspect-dicom -- --input "/path/to/test/case"
and:
npm run ingest-cases -- --input "/path/to/test/dataset" --output "./local-data"
The ingestion process must:
	•	inspect the case folders;
	•	identify DICOM files;
	•	group files into series;
	•	extract only required non-PHI metadata;
	•	determine slice order;
	•	assign neutral study identifiers;
	•	generate a manifest;
	•	preserve DICOM pixel data rather than converting it to 8-bit PNG;
	•	avoid embedding original or denoised status in browser-visible labels;
	•	create deterministic output when given the same input and seed;
	•	validate matching geometry between paired series;
	•	generate a clear error report for malformed or mismatched cases.
For local testing, serve DICOM instances from a repository-ignored local directory or a simple local development endpoint.
Do not place actual DICOM data under public/ if that risks accidental Git inclusion.
